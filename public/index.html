Conexión API

El navegador no guarda API keys. La key vive en el backend como variable de entorno.

Backend proxy /api/worldcup/calendar Normaliza calendario y resultados.
Health check /api/health Verifica proveedor, cache y modo.
Fallback local /worldcup_calendar_2026.json Funciona aunque no tengas key todavía.

Cómo correrlo

npm install
cp .env.example .env
npm start

Después abre http://localhost:3000.

Importante

Esto conecta calendario y standings deportivos. No conecta pagos, cuotas ni apuestas.
